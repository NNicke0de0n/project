# HabitTrackerBot - персональный трекер привычек.

> Легковесный Telegram-бот для трекинга привычек, регулярных напоминаний и отслеживания личного прогресса без перегруженного интерфейса.

## Проблема и решение
* **Проблема:** Людям сложно вырабатывать полезные привычки из-за отсутствия простого и доступного инструмента напоминаний.
* **Решение:** Telegram-бот, позволяющий вести учет привычек, отмечать выполнение и получать ежедневные уведомления прямо в мессенджере.

## Ключевая функциональность (MVP)
1. Добавление, редактирование и удаление привычек.
2. Ежедневные напоминания по расписанию.
3. Фиксация выполнения привычки (да/нет).
4. Просмотр статистики за неделю и месяц.

## Стек технологий
* **Язык:** Python 3.11+
* **Фреймворк:** Aiogram 3.x
* **База данных:** SQLite / PostgreSQL
* **Развертывание:** Docker
